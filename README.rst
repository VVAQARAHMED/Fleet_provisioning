nRF9151 AWS IoT
#######

## Hardware Requirements

* nRF91 development board (e.g., nRF9151-DK)

## Software Requirements

*  nRF Connect SDK V2.7.0

## Features

* Implement Fleet Provisioning by Claim 
* Save new generated device certificates to NVS flash for storage
* Connect to AWS IoT Core securely and publish frequent MQTT messages
* Implement Certificate Rotation
